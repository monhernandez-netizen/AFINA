# AFINA

**A**lfabetización **F**ónica **I**nteractiva **N**ivelada para **A**dolescentes.

Aplicación web para entrenar la conciencia fonológica jugando: escuchar, discriminar sonidos, unir imágenes con letras y palabras, contar sonidos y escribir. 4 niveles, 16 actividades. *Afiná el oído, aprendé a leer.*

Trabajo final de la Licenciatura en Alfabetización Inicial · UNaHur.

## Cómo usarla

- **En línea:** abrir el link de la página en el navegador (celular, tablet o computadora). No hace falta instalar nada.
- **Instalarla en el celular:** abrir el link con Chrome (Android) o Safari (iPhone) y elegir "Agregar a la pantalla de inicio". Después de la primera vez queda guardada y funciona **sin conexión**.
- **Sin conexión desde una carpeta:** descargar el repositorio, descomprimir y abrir `index.html`.

La app no pide registro ni guarda datos de quien la usa.

## Estructura

- `contenido/`: palabras, letras y niveles (lo que se edita).
- `js/` y `css/`: el funcionamiento y el diseño.
- `images/`, `voz/`, `sounds/`, `ayuda/`, `consignas/`: fotos y audios.
- `icons/`, `manifest.webmanifest`, `sw.js`: ícono y versión instalable.
- `version-anterior/`: la versión previa del proyecto (se conserva como archivo).
